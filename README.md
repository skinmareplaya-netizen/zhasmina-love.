# Сайт-открытка для Жасмины 💗

## Что внутри
- Анимированный конверт и письмо.
- Приглашение на встречу с возможностью согласиться или отказаться.
- Выбор среды, времени и места.
- Отдельная страница подтверждения.
- Уведомление в Telegram через сервер (секретный токен не попадает в браузер).

## Настройка Telegram
1. Открой Telegram и найди официального бота **@BotFather**.
2. Отправь `/newbot`, придумай имя и username бота.
3. Сохрани выданный **токен** в секрете. Не отправляй его Жасмине и не вставляй в HTML/JS.
4. Открой своего нового бота и нажми **Start** (или отправь `/start`).
5. В браузере открой `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` (замени `ВАШ_ТОКЕН` на токен). Найди в ответе `message.chat.id` — это твой `TELEGRAM_CHAT_ID`. Не делись ссылкой с токеном. Если `result` пуст, напиши боту ещё одно сообщение и обнови страницу.

## Запуск на компьютере
Установи Node.js версии 18 или новее. В папке проекта запусти:

macOS / Linux:
```
TELEGRAM_BOT_TOKEN='ваш_токен' TELEGRAM_CHAT_ID='ваш_chat_id' npm start
```

Windows PowerShell:
```
$env:TELEGRAM_BOT_TOKEN='ваш_токен'
$env:TELEGRAM_CHAT_ID='ваш_chat_id'
npm start
```

Открой `http://localhost:3000`.

## Публикация сайта
Подойдёт хостинг с поддержкой Node.js, например Render (Web Service):
1. Залей файлы проекта в **приватный** репозиторий GitHub (без токена!).
2. На Render создай **Web Service** из репозитория.
3. Build Command можно оставить пустым, Start Command: `npm start`.
4. В Environment добавь `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` с реальными значениями.
5. После публикации получишь ссылку вида `https://имя-проекта.onrender.com`, которую можно отправить Жасмине.

**Важно:** просто открыть `index.html` или опубликовать только статические файлы на GitHub Pages недостаточно для отправки в Telegram. Нужен работающий Node.js сервер с переменными окружения. На бесплатном хостинге сервер может засыпать, а первый запрос занимать время.

**Конфиденциальность:** сайт отправляет только выбранные дату, время и место после явного нажатия «Подтвердить и отправить». Ответ «Нет» не отправляется. Не добавляй токен бота в публичный репозиторий.

**Дата:** поле даты автоматически предлагает ближайшую среду и проверяет, что выбран именно день недели «среда».
